# ToolDocumentation

Local copies of documentation for the tools this project uses, so the
`tool-docs` skill can read them offline.

**Empty for now** — we have not agreed what goes in it yet.

## Layout

One folder per tool, lowercase: `leda/`, `zenoh/`, `kuksa/`.

## Adding a document

1. Save it in the tool's folder with a descriptive name.
2. Add a row to `SOURCES.md`.
3. Check the version matches what the repo pins.
